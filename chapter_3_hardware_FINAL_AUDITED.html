3.1

Computer architecture

CPU

The central processing unit processes instructions and data. In a Von Neumann computer, CPU units, registers and buses work together to fetch instructions/data from RAM, process them and execute the instruction.

Microprocessor

A microprocessor is an integrated circuit on a single chip. Do not use “CPU” and “microprocessor” as though the terms always mean exactly the same thing.

Examiner lens: register questions are often about what is stored, while FDE questions require movement: where → where → using which bus → what happens next.

Fetch–decode–execute cycle

1

The PC contains the address of the next instruction.

2

The address is copied from PC → MAR.

3

The PC is incremented so it points to the following instruction.

4

The address in the MAR is sent to RAM using the address bus.

5

The instruction/data at that address is transferred from RAM → MDR using the data bus.

6

The instruction is transferred from MDR → CIR.

7

The CU decodes the instruction and sends control signals using the control bus.

8

The instruction is executed; the ALU/ACC or other components are used as required.

Built from supplied MS: Cambridge explicitly credits PC, MAR and MDR; PC→MAR, PC incrementing, MAR→RAM using the address bus, RAM→MDR using the data bus, MDR→CIR/CU, and CU control signals using the control bus.
Common trap: “The CPU fetches, decodes and executes” names the stages but does not describe the process.

CPU performance & instruction set

Clock speed

The clock synchronises CPU operations. A clock of 3.5 GHz, for example, represents about 3.5 billion cycles per second. A higher clock speed can allow more processing cycles per second.

Number of cores

More cores can improve performance because different cores can execute FDE cycles/instructions simultaneously.

Cache size

Larger cache can improve performance because more frequently used data/instructions can be accessed quickly rather than repeatedly accessing slower RAM.

Instruction set

An instruction set is the list of machine-code commands that can be processed by the CPU.

Answer construction: for “explain how X improves performance”, give the change → what happens inside the CPU → why that makes processing faster.

Embedded systems

Core idea

An embedded system performs a dedicated/limited function, unlike a general-purpose computer that performs many different functions.

Syllabus contexts include domestic appliances, cars, security systems, lighting systems and vending machines.

Characteristics seen in the supplied MS

  • single/limited or dedicated function
  • dedicated hardware
  • uses a microprocessor
  • function is not easily changed
EmbeddedDesigned around a particular function/task.
General purposeDesigned to perform many functions; e.g. PC/laptop.

3.3

Data storage

Primary storageDirectly accessed by the CPU. Includes RAM and ROM.
Secondary storageNot directly accessed by the CPU; needed for more permanent storage.

RAM and ROM

RAM — Random Access Memory

  • primary storage directly accessible by the CPU
  • stores data/instructions currently in use
  • temporary and volatile
  • fast access compared with secondary storage
  • supports the fetch stage because instructions/data currently required can be accessed by the CPU

ROM — Read Only Memory

  • non-volatile/permanent storage
  • can hold instructions needed to start the computer
  • examples credited in supplied MS include BIOS/bootstrap/bootloader/firmware
  • useful for instructions/data that should not normally change
Why both? RAM provides fast working storage for currently running data/instructions; ROM retains essential fixed/start-up instructions when power is removed.

Secondary storage technologies

TechnologyHow it stores/reads dataSyllabus examples
MagneticPlatters are divided into tracks and sectors; electromagnets are used to read/write data.HDD
OpticalA laser is used to create/read pits and lands on a reflective surface.CD, DVD, Blu-ray
Solid-state / flashUses NAND or NOR technology; transistors are used as control gates and floating gates.SSD, SD card, USB drive

Comparison knowledge appearing in the supplied papers

Solid-state

  • no moving parts
  • faster access
  • lower power consumption
  • quiet
  • more durable/robust
  • can have large capacity
  • more expensive per GB

Optical — contrasting points

  • has moving parts in the drive
  • slower access
  • higher power use in the supplied comparison
  • can make more noise
  • less robust
  • smaller storage-capacity limit in the supplied comparison
  • cheaper per GB
Selection questions: do not simply say “SSD is better”. Match a characteristic to the scenario: e.g. no moving parts → greater robustness for a portable device.

Virtual memory

1

Virtual memory is created using part of secondary storage.

2

It is needed when there is insufficient RAM for the data/programs that need to run.

3

Pages not currently required can be moved from RAM → virtual memory, creating space in RAM.

4

When a page is required again, it is transferred back to RAM; pages are moved between RAM and virtual memory as needed.

Cloud storage

Cloud storage stores data on remote physical servers/storage and is accessed remotely, commonly over a network/internet connection. “Cloud” does not mean the data has no physical storage.

Advantages evidenced in supplied MS

  • access data remotely/from other devices
  • if a local device is lost or breaks, remote data can remain available
  • no need for the user to maintain the storage hardware
  • third party may maintain hardware/security
  • storage resources can be increased/decreased
  • can reduce need for local secondary-storage capacity
  • may reduce purchase cost of local storage hardware

What to compare

The syllabus asks for advantages and disadvantages compared with local storage. Structure answers as cloud characteristic → consequence → why that matters in the scenario.

3.4

Network hardware

Network Interface Card (NIC)

A computer needs a NIC to access a network. Supplied MS points include sending/receiving network data, providing a physical connection, converting network/computer data as needed for transmission, and being assigned an IP address.

MAC address

A NIC is given a MAC address at manufacture. It is usually written in hexadecimal and is formed from a manufacturer code and a serial/unique device code.

MAC, IP, IPv4 and IPv6

MACAssociated with the NIC; given at manufacture; usually hexadecimal; manufacturer + serial/device code.
IPAllocated by the network; identifies/addressing a device on the network; can be static or dynamic.
