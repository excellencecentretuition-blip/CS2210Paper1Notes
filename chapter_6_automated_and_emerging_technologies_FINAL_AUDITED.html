6.1

Automated systems

The syllabus requires students to describe how sensors, microprocessors and actuators work together to create automated systems, and to describe advantages and disadvantages in a given scenario. Required contexts include industry, transport, agriculture, weather, gaming, lighting and science.

Core idea: an automated system monitors a real-world condition, processes the input against programmed/stored rules or values, and controls an output without requiring continuous human intervention.

The control loop — the process students must be able to explain

1Sensor measures a physical quantity in the environment.
2The sensor provides data/readings to the microprocessor. Past-paper mark schemes often explicitly require the data to be received continually.
3The microprocessor processes/compares the reading with stored or preset data/value(s).
4The result of the comparison determines whether action is required.
5If action is required, the microprocessor sends a control signal to an actuator/output device.
6The actuator causes a physical change in the real world.
7The sensors take further readings, so the process can repeat as a feedback/control loop.
ENVIRONMENT→SENSOR→MICROPROCESSOR→ACTUATOR→ENVIRONMENT CHANGES↺

Roles must not be confused

ComponentRole in the automated systemCommon exam mistake
SensorMeasures/captures a physical property and supplies input data.Saying the sensor decides what action to take.
MicroprocessorReceives and processes sensor data, compares it with stored/preset data and sends control signals.Saying it physically opens, moves or turns something.
ActuatorReceives the control signal and causes a physical action/change.Calling it a sensor or saying it analyses data.

Scenario method

Cambridge repeatedly makes the control loop specific to a situation. Do not write only “sensor → processor → actuator”. Name the quantity being sensed, the stored threshold/condition, the comparison and the resulting action.

Weather-station pattern from the supplied paper: temperature sensor supplies data → microprocessor receives it → compares it with the preset value 40°C → if greater than 40°C, sends a signal to trigger an alert.

Advantages and disadvantages

Possible advantages

Can perform repetitive/mundane work; can operate for long periods or at inconvenient times; can reduce human exposure to dangerous/adverse conditions; can improve consistency/precision; can create technical/maintenance roles. The valid point must fit the scenario.

Possible disadvantages

Initial cost and maintenance; faults can stop or damage the process; workers may lose jobs or become deskilled; staff may need training; systems may have difficulty with unexpected events unless designed/adapted to handle them.

Examiner lens: “Give an advantage” usually needs a benefit to the named stakeholder. A generic statement such as “it is faster” is weaker than explaining what becomes faster and why that matters in the stated situation.
Automation advantages/disadvantages — apply them: Advantages can include continuous operation, consistent/repeatable output, greater precision, faster processing, reduced need for people to perform mundane/repetitive work, reduced exposure to dangerous/adverse conditions, and creation of maintenance/technical roles. Disadvantages can include purchase/maintenance cost, malfunction, loss/replacement of jobs and de-skilling. Supplied 2025 MS specifically credits employees not needing repetitive tasks, overnight work or adverse-weather work, alongside maintenance jobs, de-skilling and job replacement.
Required application areas: Be ready to apply automated systems to industry, transport, agriculture, weather, gaming, lighting and science. The same advantage is not automatically valid in every scenario: connect it to the task being automated.
MS precision — automated control: Sensor data is received by the microprocessor, compared against stored/preset data or a threshold, and when action is required the microprocessor sends a signal to an actuator/output device. New readings allow the process to repeat continuously.
2025 weather-station marking pattern: microprocessor receives sensor data → compares it with a preset value → if the measured value crosses that preset, sends a signal to trigger the required output/alert.
6.2

Robotics

The syllabus definition is precise: robotics is a branch of computer science that incorporates the design, construction and operation of robots.

Three characteristics of a robot

1

Mechanical structure/framework

A robot has a physical structure that allows it to interact with or operate in the physical world.

2

Electrical components

These can include sensors, microprocessors and actuators.

3

Programmable

Its operation is controlled by programmed instructions.

Important: a device is not automatically a robot merely because it contains a microprocessor, is “smart”, uses AI or is an embedded system. Cambridge can ask students to use the robot characteristics to explain why a device is or is not a robot.

Where robots can be used

Syllabus areaTypical role to understand
IndustryManufacturing, assembly or repetitive production tasks.
TransportMovement, navigation or transport-related automated operations.
AgriculturePlanting, monitoring, harvesting or field operations.
MedicineAssisting precise medical/surgical procedures.
Domestic settingsTasks such as robotic vacuum cleaning.
EntertainmentInteractive or programmed entertainment applications.

Syllabus examples include factory equipment, domestic robots and drones.

Robot vs automated system

Automated system

The key idea is automatic monitoring/control of a process, commonly through sensor → microprocessor → actuator collaboration.

Robot

Must satisfy the robot characteristics: physical/mechanical structure, electrical components and programmability. A robot may itself be used as part of an automated system.

Advantages and disadvantages of robots

Cambridge tends to make these stakeholder- and scenario-specific. A farmer, employee, hospital, business owner and patient can experience different benefits or drawbacks from the same technology.

Mark-winning structure: feature of robot/automation → consequence → consequence for the named person or organisation.
Robot applications — syllabus checklist: Robots can be used in industry, transport, agriculture, medicine, domestic settings and entertainment. Advantages/disadvantages must be tied to the context: e.g. precision and repeatability in manufacturing or surgery, operation in dangerous environments, continuous work, but also high cost, maintenance needs, possible malfunction and effects on employment.
MS precision — identifying a robot: Apply all three characteristics: mechanical structure/framework, electrical components including sensors, microprocessors and actuators, and being programmable. In the supplied 2025 smart-speaker question, the credited explanation is that it has no mechanical structure, no actuators, and therefore cannot move itself.
6.3

Artificial intelligence (AI)

The syllabus defines AI as a branch of computer science dealing with the simulation of intelligent behaviours by computers.

Main characteristics Cambridge requires

Data + rules

AI involves a collection of data and rules for using that data.

Reasoning

It has the ability to reason — to use data/rules to reach decisions, results or predictions.

Learning/adaptation

AI can include the ability to learn and adapt. This is particularly associated with machine learning.

Do not define all AI as machine learning. The syllabus limits the AI systems studied here to expert systems and machine learning, but they are distinct ideas.
AI definition — exact depth: Artificial intelligence is a branch of computer science dealing with the simulation of intelligent behaviours by computers. Its characteristics include a collection of data, rules for using that data, the ability to reason, and it can include the ability to learn and adapt.

Expert systems

An expert system is an AI system designed to use stored specialist knowledge and rules to reach a conclusion, recommendation, diagnosis or decision in a restricted domain.

Four syllabus components

ComponentRole
Knowledge baseStores facts/knowledge relevant to the expert domain.
Rule baseStores rules that are applied to the knowledge/data.
Inference engineApplies the rules to the knowledge/data, reasons through the information, can decide what to ask next and derives a result/diagnosis/decision.
InterfaceAllows the user to input information and receive/view the system's output.

How an expert system operates

1The user enters facts/symptoms/data through the interface.
2The inference engine processes the supplied information and may decide which question to ask next.
3Input is located in/compared with the knowledge base.
4The inference engine applies the rule base to the knowledge/data.
5A diagnosis/result/solution/decision is produced.
6The result is presented through the interface.
Past-paper lesson: knowing only the four component names is not enough. Cambridge also asks how they interact. The inference engine is the active reasoning component; the knowledge base and rule base are not interchangeable.
Expert-system components: Knowledge base stores the facts/knowledge; rule base stores rules that are applied to the knowledge/data; inference engine applies the rules, makes deductions and can decide which question to ask next; the user interface collects user input and presents questions/results.
Expert-system operation — MS chain: The user enters data through the interface → the inference engine can decide which questions to ask, with later questions depending on earlier answers → input/symptoms are located in or compared with the knowledge base → the rule base is applied → the inference engine reaches a conclusion/diagnosis → the result is presented through the interface.

Machine learning

The exact syllabus core is: machine learning is when a program has the ability to automatically adapt its own processes and/or data.

What “learning” means in exam scenarios

1The system gathers/receives data from operation or previous examples.
2It identifies useful patterns, trends or outcomes in that data.
3It can adapt its own processes and/or data.
4Past results/feedback can influence later decisions or predictions.
5Its future performance can improve as its learned data/processes become better suited to the task.
Supplied-paper applications: a weather system analyses trends and adapts predictions; a robot can remember obstacles/routes and improve efficiency; a robot vacuum can learn room shape, dirty areas and efficient routes.

AI, expert system and machine learning — keep them separate

TermCentral idea
Artificial intelligenceBroad branch concerned with simulating intelligent behaviour.
Expert systemUses a knowledge base, rule base, inference engine and interface to emulate specialist decision-making in a domain.
Machine learningA program automatically adapts its own processes and/or data.
Cambridge application pattern: “Explain how machine learning improves X” → state adaptation/learning → identify the scenario data it can learn → explain how that changes a future action/prediction → link to an improvement.
2025 weather machine-learning depth: The system can analyse data for trends/patterns, make predictions from them, receive feedback on predictions, change later predictions using that feedback, learn seasonal patterns and improve by adapting rules/processes.
2025 voice-recognition machine-learning depth: The system can gather examples from the same/different voices, identify voice patterns, adapt its processes, store successful/unsuccessful commands, learn different ways to make the same request, learn pronunciations/accents, learn from many voices and learn to ignore background/environmental noise.

Common traps to eliminate

  • Do not say a sensor “controls” the system; it supplies input data.
  • Do not say a microprocessor physically moves a device; it sends the control signal.
  • Do not forget the comparison with stored/preset data in an automated-system explanation.
  • Do not call every automated device a robot.
  • Do not call every AI system machine learning.
  • Do not swap the knowledge base and rule base.
  • Do not describe machine learning only as “the computer learns”; state that it adapts its own processes and/or data and apply that to the scenario.
  • For advantages/disadvantages, identify whose advantage/disadvantage is being asked for.
